# Discord-статус

В Veyra 0.6.0 уже указан публичный Application ID **1557568278769967145**. На обычном запуске статус включён; его можно выключить в настройках лаунчера. Нужна запущенная настольная версия Discord. В Discord также должно быть разрешено отображение текущей активности.

С этим ID Discord подтвердил активность с именем **Veyra**. Чтобы получить заголовок **«Играет в VeyraLauncher»**, откройте своё приложение в [Discord Developer Portal](https://discord.com/developers/applications), поменяйте **Name** в **General Information** на **VeyraLauncher** и сохраните. Затем перезапустите лаунчер. Код и ID менять не нужно: название заголовка задаёт Discord.

В библиотеке статус сообщает о подготовке к игре. Пока работает процесс Minecraft, показываются название сборки, версия игры, загрузчик и время с запуска процесса. Переключение выбранной сборки во время игры не меняет сведения о запущенной игре. Закрытие лаунчера или выключение переключателя очищает активность; последующий запуск Discord подхватывается автоматически.

Интеграция использует локальный [Discord RPC over IPC](https://github.com/discord/discord-api-docs/blob/main/developers/topics/rpc.mdx): handshake, SET_ACTIVITY, ping/pong. Бот, токен пользователя и вход через Discord не нужны. В Discord не передаются пути к файлам, локальный ник или токены Minecraft.

Проверка протокола: `node scripts/discord-check.js`. Она использует отдельный локальный канал и не изменяет реальный статус пользователя. Автоматические проверки интерфейса запускаются с отдельными данными и с выключенным Discord.
