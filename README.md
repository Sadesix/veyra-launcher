# Veyra Launcher

Veyra — лаунчер Minecraft Java Edition для Windows. В главном окне остаётся узкая панель с иконками; сборки, установка и настройки находятся в одной рабочей области.

## Возможности

- Версия 7.0 (0.7.0): несколько клиентов одновременно. Кнопка **+ Клиент** запускает ещё один процесс, а панель **Сервер** показывает все клиенты и позволяет останавливать каждый отдельно. Для локальных профилей ники автоматически становятся различными: Nick, Nick_2 и далее; Microsoft-профиль нельзя одновременно дублировать. Суммарная выделенная память клиентов и сервера проверяется перед запуском.
- Повторный запуск Veyra открывает уже работающий лаунчер. Одно управляющее приложение предотвращает параллельную запись общих настроек и подготовку одной серверной папки двумя лаунчерами; игровые клиенты запускаются независимо из него.
- Первый клиент использует обычную папку сборки. Дополнительные — собственные папки **.veyra-clients/<id>** внутри сборки с копиями модов, конфигурации и паков, собственными сохранениями и нативными библиотеками. Основные сохранения не копируются и не разделяются. Папки сохраняются после выхода. Файл владельца основной папки предотвращает её повторное использование, пока предыдущий клиент или лаунчер ещё работает. Время одновременных клиентов одной сборки учитывается без удвоения.
- Локальный выделенный сервер: **Сервер → принять Minecraft EULA → Запустить сервер**. Vanilla, Fabric, Forge и NeoForge получают серверные компоненты той же версии в отдельную папку **.veyra-server**; сервер использует свои сохранения. Порт **25565** проверяется перед подготовкой и запуском. Адрес **127.0.0.1:25565** можно скопировать; кнопка **Клиент → сервер** запускает подходящий клиент с подключением. Первая установка требует интернета. Используются [официальный серверный лаунчер Fabric](https://fabricmc.net/use/?page=server) и [установщик NeoForge](https://docs.neoforged.net/user/docs/server/).
- Сервер слушает **0.0.0.0:25565** на всех IPv4-интерфейсах. В панели показаны IP-адреса компьютера для подключения из сети; на самом ПК используется 127.0.0.1:25565. Работают локальные профили (online-mode=false), отключены RCON и Query. Лаунчер не меняет брандмауэр и маршрутизатор; доступ извне зависит от их настроек. Серверные моды отбираются по метаданным Modrinth или environment из fabric.mod.json; клиентские, неопределённые моды и моды с пропущенными обязательными зависимостями показываются в списке исключённых. Конфигурация переносится только при первом создании; серверные настройки и мир сохраняются. Пользовательские файлы сервера не перезаписываются при совпадении имени с новым модом. Изменение файлов сборки блокируется, пока работают управляемые клиенты или сервер.
- Остановка сервера отправляет команду **stop**, чтобы сохранить мир. Закрытие лаунчера ждёт остановки сервера. Если сервер не отвечает, панель позволяет повторить остановку либо подтвердить принудительное завершение; оно может потерять несохранённые изменения. Чужие процессы на занятом порту не завершаются.
- Отдельная папка игры для каждой сборки: Документы/Veyra Launcher/instances/<id>. Внутри находятся собственные mods, saves, resourcepacks, screenshots, версии, библиотеки и ресурсы.
- Vanilla, Fabric, NeoForge и Forge. Доступные версии загрузчика подбираются для выбранной версии Minecraft.
- Автоматический выбор подходящей Java. Если её нет на компьютере, Veyra загружает официальный runtime Minecraft. При желании можно выбрать java.exe или javaw.exe вручную для всего лаунчера или отдельной сборки.
- Настройка памяти для всех сборок и индивидуальное переопределение. Верхняя граница зависит от ОЗУ компьютера; 2 ГБ оставляются системе.
- Прогресс установки, отмена, повторная попытка, журнал и кнопки открытия папок. Во время установки сбоку разворачивается консоль со временем строк, реальными этапами задач и stdout/stderr установщиков Forge и NeoForge. Просмотр можно поставить на паузу, перейти к последней строке, скопировать вывод и открыть снова после завершения. Панель хранит последние 400 строк текущей установки; полный вывод остаётся в журнале.
- Своя обложка, цвет, название и заметка для каждой сборки. Избранные сборки закрепляются первыми; капсула показывает общее время игры, текущий сеанс, число запусков и дату последней игры.
- Студия сборки: большая обложка с движением за курсором, живой предпросмотр названия и заметки, галерея фонов и отдельная вкладка параметров игры. Включены восемь WebP-фонов из предоставленного архива. Новая сборка получает случайный фон, который сохраняется между запусками; существующая обложка остаётся прежней. Кнопка случайного выбора в студии меняет только предпросмотр до сохранения. Своё изображение выбирается через диалог файлов и применяется сразу.
- Каталог Modrinth для модов, шейдеров и ресурспаков: поиск, категории, сортировка и страницы. Версии модов проверяются по Minecraft и загрузчику сборки; версии ZIP-паков — по Minecraft. Есть выбор конкретного выпуска и отдельное включение Beta / Alpha. Перед установкой показываются обязательные зависимости и размер загрузки; зависимости проектов устанавливаются автоматически, включая точные версии и вложенные зависимости.
- Корзина в новой мастерской сборки: добавляйте проекты одним нажатием, продолжайте искать, меняйте версии и скачивайте весь набор кнопкой **Собрать и скачать**. Общие зависимости добавляются один раз; конфликтующие требования показываются до установки. До 40 выбранных проектов в каждой сборке, включая моды, шейдеры и ресурспаки. Выбор сохраняется после каждого изменения и восстанавливается после перезапуска или краша. Отмена и ошибка оставляют корзину; успешная установка очищает её и сохраняет открытый каталог, запрос и фильтры.
- Менеджер содержимого: поиск и фильтры локальных файлов, включение/отключение JAR и ZIP, импорт своих файлов, обновление из Modrinth, открытие папок, корзина и восстановление. Обязательную библиотеку нельзя отключить, пока включён зависимый мод. При обновлении прежний файл сохраняется в корзине и восстанавливается отключённым, чтобы не создать дубликат активного мода.
- Сохранения: импорт папки с level.dat, копия, переименование папки, поиск, сортировка и корзина. Имя сохранения внутри Minecraft при переименовании папки остаётся прежним. Изменение содержимого блокируется, пока игра работает. Распакованные ресурспаки и шейдеры можно открыть или убрать в корзину; переключатель доступен для ZIP-файлов.
- Discord Rich Presence через локальное приложение Discord. В библиотеке отображается подготовка к игре, при запуске — сборка, версия Minecraft, загрузчик и время сеанса. Переключатель в настройках выключает активность сразу. Если Discord закрыт или перезапущен, Veyra подключается автоматически. Используется Application ID 1557568278769967145; название заголовка активности берётся из зарегистрированного приложения (сейчас Veyra). [Настройка имени](docs/discord.md).
- Приветствие по времени суток и вашему нику. При переключении сборки обложка и содержимое плавно сменяются, карточки не пересоздаются.
- Меню по правой кнопке на сборке: запуск/остановка, переименование, смена обложки, избранное, папка, настройки и удаление с подтверждением. Доступна навигация стрелками, Enter и Escape.
- Создание сборки в выезжающей панели: плитки версий Minecraft и загрузчиков, поиск, релизы и Snapshots. Версии загрузчиков подписаны также на карточках и в сведениях о сборке. Рекомендуемые и стабильные версии отмечены в выборе. Щелчок снаружи или Escape закрывает панель, включая заполненное поле поиска.
- Быстрое переименование кнопкой у названия или клавишей F2 без сдвига описания и кнопок. Новое имя появляется с эффектом стирания и набора, последнее переименование можно отменить кнопкой в уведомлении. Обложка плавно движется за курсором; запуск показывается небольшой панелью в карточке сборки.
- Локальный профиль для одиночной игры.
- Панель профиля с быстрой сменой локального ника: нажмите профиль вверху или слева, введите ник и нажмите Enter. Переключатель «Разрешить любые символы» открывает кириллицу, пробелы и эмодзи (1–32 символа без управляющих символов). По умолчанию используются 3–16 латинских букв, цифр и _. Серверы могут предъявлять собственные требования к имени; смена локального ника меняет UUID игрока.
- Код Microsoft-входа через браузер и код подтверждения, переключения профилей и обновления сессии сохранён. Разработка привязки приостановлена: вкладка Microsoft, вход и настройка Client ID скрыты из интерфейса.
- Фон по умолчанию непрозрачный, с картинкой. В настройках «Атмосфера» доступны «С картинкой» / «Без картинки», прозрачность (0–60%), яркость фонового оформления (30–150%) и размытие фонового изображения (0–40 px), живой предпросмотр и три пресета. Этот переключатель меняет общий фон лаунчера; обложки сборок сохраняются. При включённой прозрачности используется системный Acrylic на Windows 11 22H2+; на остальных системах окно остаётся непрозрачным. Радиус системного Acrylic задаётся Windows.
- Плавный индикатор навигации, анимации иконок, панели создания, меню и смены обложки. Настройка уменьшенного движения в системе сокращает эффекты. Текст интерфейса не выделяется; поля ввода, журнал, пути и заметки доступны для копирования.
- В патче 0.6.1 добавлены анимации переноса проекта в корзину, появления карточек, раскрытия и сворачивания боковых панелей и взаимодействия с иконками. Крестики имеют неподвижную область нажатия минимум 44 × 44 px; при наведении движется только сама иконка. Окно запоминает размер, положение и развёрнутое состояние; при изменении мониторов возвращается в доступную область экрана.
- Предупреждения полей оформлены внутри интерфейса, с подсветкой и пояснением. Пустое название при создании и переименовании заменяется первым свободным: **Сборка**, **Сборка 2**, **Сборка 3** и далее.
- Понятные сообщения о сбоях и кнопка открытия отчёта. Исправление ошибки главного меню NeoForge 26.3.0.56-beta и более надёжная распаковка нативных библиотек.
- Кнопка «Остановить игру» у запущенной сборки и внизу окна: завершает процесс Minecraft. Остановка пользователем не считается вылетом.

Локальный профиль доступен сразу. Подготовленный Microsoft-вход скрыт по текущему решению; для будущего подключения потребуется зарегистрированное приложение Veyra с доступом к Minecraft API. [Сохранённая инструкция](docs/microsoft-setup.md).

## Как начать

1. Нажмите **Новая сборка**.
2. Выберите версию Minecraft и загрузчик. Название можно оставить пустым.
3. Нажмите **Создать сборку**. Первая установка требует подключения к интернету. Лаунчер подберёт Java и загрузит игру в новую папку.
4. После установки нажмите **Играть**.

Если не хотите заниматься Java, оставьте значение **Автоматически**. Для модов нажмите кнопку с пазлом у выбранной сборки или пункт **Моды и содержимое** в меню по правой кнопке. В **Каталоге Modrinth** набирайте проекты в корзину кнопкой **Добавить**. Меню с тремя точками открывает выбор версии. Когда набор готов, нажмите **Собрать и скачать** — зависимости подберутся автоматически. Свою обложку и параметры сборки меняйте в студии кнопкой с шестерёнкой.

Файлы с CurseForge можно добавить кнопкой **Добавить файлы**. Прямого каталога CurseForge в этой версии нет: для него необходим собственный ключ API. Зависимости вручную добавленных файлов лаунчер не определяет.

## Данные и обновление со старой версии

Новые сборки хранятся в папке Документы/Veyra Launcher/instances. Её путь виден в настройках и открывается кнопкой. Удалённые из списка управляемые сборки перемещаются в соседнюю папку trash для ручного восстановления. Настройки лаунчера и журнал остаются в пользовательской папке приложения.

Выбранные проекты хранятся в **content-carts.json** в пользовательской папке лаунчера, отдельно для каждой сборки. Размер и положение окна — в **window-state.json**. Эти файлы сохраняются при обновлении portable-приложения. Если файл корзины повреждён, Veyra сообщает об этом и оставляет его для восстановления.

Время игры учитывается с запуска процесса Minecraft, пока открыт Veyra, и сохраняется каждые 15 секунд, при остановке игры и закрытии лаунчера. Прошлое время до версии 0.4.0 восстановить невозможно; отсчёт начинается с обновления. Если закрыть лаунчер, оставив игру запущенной, дальнейшее время этого сеанса не учитывается.

При первом запуске старая сборка Veyra, если она есть, добавляется в библиотеку. Её папка не переносится. Сборки, созданные прошлой версией в AppData, продолжают работать на прежнем месте.

## Запуск из исходников

Понадобятся Windows, Node.js 22+ и npm:

    npm install
    npm start

Проверка интерфейса и основных действий:

    npm run smoke
    npm run check:auth
    npm run check:accounts
    node scripts/experience-check.js
    node scripts/refinement-check.js
    node scripts/stop-game-check.js
    node scripts/content-check.js
    node scripts/content-ui-check.js
    node scripts/cart-check.js
    node scripts/cart-ui-check.js
    node scripts/transaction-check.js
    node scripts/patch-check.js
    node scripts/sessions-check.js
    node scripts/server-check.js
    node scripts/studio-check.js
    node scripts/discord-check.js

«check:auth» проверяет протокол на тестовых ответах. «check:accounts» проверяет смену ника и скрытие Microsoft-функций. В этом скрипте сохранены проверки входа, Windows DPAPI и параметров запуска: они возобновятся после включения MICROSOFT_UI_ENABLED в renderer/renderer.js. Им нужна Java 25 из runtime Veyra или из папки VEYRA_JAVA_HOME. Реальный вход требует собственного Client ID и аккаунта с Minecraft Java Edition.

«refinement-check» проверяет версии загрузчиков, геометрию переименования, эффект набора и отмену, расширенный ник в параметрах запуска, фон без картинки и сохранение настроек. Для консоли выполняется настоящая цепочка установки XMCL на маленьких тестовых файлах; Java-процессор и игра заменены реальными дочерними процессами Node. Проверяются потоки stdout/stderr, пауза просмотра, копирование, отмена установки и компактная анимация запуска. Пользовательские сборки не затрагиваются.

«cart-ui-check» проверяет реальное сохранение выбора через IPC, принудительно завершает только тестовый процесс лаунчера, восстанавливает корзину, отменяет и повторяет общую загрузку. Ответы Modrinth и CDN заменены тестовыми данными. «transaction-check» завершает дочерний процесс на каждом этапе переноса файлов и после записи сведений, проверяет восстановление прежних модов и безопасный повтор завершённой установки. «patch-check» проверяет нестандартные предупреждения, автоматические названия, нажатия на края крестиков и точное восстановление геометрии окна. Проверки интерфейса принимают путь к собранному EXE вторым аргументом.

Создание переносимого .exe:

    npm run icon
    npm run dist

Готовый файл будет в dist. Для проверки установки реальной версии из исходников доступен «node scripts/install-check.js vanilla 1.21.8»; второй аргумент можно заменить на fabric, neoforge или forge.

## Что пока вне этой версии

Автоматический отбор серверных модов использует заявленную совместимость и не гарантирует отсутствие ошибок внутри самих модов. Неопределённые моды можно добавить вручную в папку сервера после проверки. Сохраняется набор пользовательских серверных модов; лаунчер меняет только файлы, которые сам синхронизировал. Одновременные процессы и память отображаются для текущего запуска лаунчера. Для старых Snapshots поддержка автоматического подключения зависит от аргументов конкретной версии; адрес всегда можно вставить в Minecraft вручную.

«sessions-check» проверяет реальные дочерние процессы и TCP-порт 25565, изоляцию папок, разные ники, блокировку изменения сборки, явное подтверждение EULA, фильтрацию модов, подключение и отдельную остановку. Java-клиенты и сервер заменены тестовыми процессами Node; это проверка управления, а не полноценного игрового процесса. «server-check» проверяет варианты подготовки загрузчиков, занятый порт, отмену установщика и сохранение пользовательских файлов на тестовых ответах загрузки.

Совместимость каталога определяется метаданными Modrinth; ошибки внутри модов и незаявленные конфликты могут проявиться при запуске игры. Обязательные зависимости проектов устанавливаются автоматически. Внешние зависимости без ссылки на проект и дополнительные файлы типа required-resource-pack требуют ручной установки; Veyra сообщает об этом до изменения сборки. Шейдерам нужен подходящий движок, например Iris: сама загрузка ZIP не устанавливает его.

Загрузки из Modrinth сохраняются сначала во временную папку внутри самой сборки, проверяются по размеру и SHA-512/SHA-1 и только затем перемещаются в игровые папки. Ошибка, отмена скачивания или ошибка записи сведений откатывает изменения. При невозможности восстановить заблокированный файл резервные копии сохраняются для ручного восстановления. В каталоге не производится распаковка или запуск скачанных файлов.

Перемещения при установке каталога записываются заранее в **.veyra-content-transaction.json** внутри сборки. После аварийного завершения Veyra восстанавливает незавершённую установку перед работой с содержимым или запуском игры; уже завершённая установка остаётся на месте. Повторное скачивание запускается вручную из сохранённой корзины. Частично скачанные файлы не продолжаются с места остановки. Если файл был изменён извне после сбоя, автоматическое восстановление останавливается и сохраняет резервные копии.

## Совместимость NeoForge 26.3.0.56-beta

В этой версии NeoForge проверка обновлений может вернуть null, а код главного меню вызывает у результата ordinal(). Veyra подключает небольшой Java agent только для этой версии: незавершённая проверка получает статус FAILED, остальные результаты сохраняются. Официальные JAR игры остаются исходными. Исходник — compat/NeoVersionGuard.java; включённый JAR — assets/compat/neoforge-version-guard.jar.

Для пересборки агента нужна Java 25 с javac и jar. Задайте VEYRA_JAVA_HOME или используйте runtime, установленный Veyra, затем выполните «npm run compat». Проверка реального запуска на имеющихся ресурсах: «node scripts/launch-compat-check.js ПУТЬ_К_СБОРКЕ»; отдельная тестовая игра создаётся в test-output/compat-game. Она доходит до главного меню и проверяется 50 секунд.
