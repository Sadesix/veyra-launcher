# Veyra Launcher

**Veyra Launcher** — современный лаунчер Minecraft Java Edition для Windows с фиолетовым минималистичным интерфейсом и локальным профилем.

## Что уже работает

- Выбор официальных vanilla-релизов Minecraft; snapshots можно включить в настройках.
- Загрузка клиента, библиотек и ресурсов с прогрессом и отменой.
- Запуск Minecraft через локальный профиль с выбранным ником.
- Настройка Java, памяти и папки игры.
- Новый интерфейс Veyra: дашборд, карточка сборки, быстрые действия, системная панель и журналы состояния.
- Собственный логотип, иконка приложения и кастомные оконные кнопки.

Локальный профиль запускает игру **без входа в Microsoft**. Серверы, которым нужна лицензированная учётная запись, с ним недоступны. Microsoft-авторизация, менеджер модов и полноценная система нескольких сборок пока не подключены — соответствующие разделы интерфейса уже заложены под следующий этап.

## Быстрый старт

Если в `dist` уже лежит `Veyra-Launcher-0.1.1-x64.exe`, запускай его. Для первого получения списка версий и установки Minecraft нужен интернет.

1. Выбери версию Minecraft на главном экране.
2. В настройках укажи ник, Java и объём памяти.
3. Нажми **«Установить версию»**, а после установки — **«Играть»**.

Veyra проверяет версию Java перед запуском. По умолчанию используется `java` из `PATH`; можно явно выбрать `java.exe` или `javaw.exe`.

## Запуск из исходников

Нужны Windows, Node.js 22+ и npm:

```powershell
npm install
npm start
```

Сборка portable `.exe`:

```powershell
npm run icon
npm run dist
```

Готовый файл появится в `dist`.

## Совместимость с ранней Obsidian-сборкой

Veyra использует новый маркер `.veyra-installed`, но при сканировании также понимает старый `.obsidian-installed`, поэтому уже скачанные версии Minecraft не обязаны устанавливаться заново.
