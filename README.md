# Veyra Launcher

Veyra — лаунчер Minecraft Java Edition для Windows. В главном окне остаётся узкая панель с иконками; сборки, установка и настройки находятся в одной рабочей области.

## Возможности

- Отдельная папка игры для каждой сборки: Документы/Veyra Launcher/instances/<id>. Внутри находятся собственные mods, saves, resourcepacks, screenshots, версии, библиотеки и ресурсы.
- Vanilla, Fabric, NeoForge и Forge. Доступные версии загрузчика подбираются для выбранной версии Minecraft.
- Автоматический выбор подходящей Java. Если её нет на компьютере, Veyra загружает официальный runtime Minecraft. При желании можно выбрать java.exe или javaw.exe вручную для всего лаунчера или отдельной сборки.
- Настройка памяти для всех сборок и индивидуальное переопределение. Верхняя граница зависит от ОЗУ компьютера; 2 ГБ оставляются системе.
- Прогресс установки, отмена, повторная попытка, журнал и кнопки открытия папок.
- Своя обложка, цвет, название и заметка для каждой сборки. Избранные сборки закрепляются первыми; капсула показывает общее время игры, текущий сеанс, число запусков и дату последней игры.
- Приветствие по времени суток и вашему нику. При переключении сборки обложка и содержимое плавно сменяются, карточки не пересоздаются.
- Меню по правой кнопке на сборке: запуск/остановка, переименование, смена обложки, избранное, папка, настройки и удаление с подтверждением. Доступна навигация стрелками, Enter и Escape.
- Создание сборки в выезжающей панели: плитки версий, поиск, релизы и Snapshots. Щелчок снаружи или Escape закрывает панель.
- Быстрое переименование кнопкой у названия или клавишей F2, плавная обложка с движением за курсором и анимированная заставка запуска.
- Локальный профиль для одиночной игры.
- Панель профиля с быстрой сменой локального ника: нажмите профиль вверху или слева, введите ник и нажмите Enter.
- Код Microsoft-входа через браузер и код подтверждения, переключения профилей и обновления сессии сохранён. Разработка привязки приостановлена: вкладка Microsoft, вход и настройка Client ID скрыты из интерфейса.
- Фон по умолчанию непрозрачный. В настройках «Атмосфера» доступны прозрачность (0–60%), яркость фонового оформления (30–150%) и размытие фонового изображения (0–40 px), живой предпросмотр и три пресета. При включённой прозрачности используется системный Acrylic на Windows 11 22H2+; на остальных системах окно остаётся непрозрачным. Радиус системного Acrylic задаётся Windows.
- Плавный индикатор навигации, анимации иконок, панели создания, меню и смены обложки. Настройка уменьшенного движения в системе сокращает эффекты. Текст интерфейса не выделяется; поля ввода, журнал, пути и заметки доступны для копирования.
- Понятные сообщения о сбоях и кнопка открытия отчёта. Исправление ошибки главного меню NeoForge 26.3.0.56-beta и более надёжная распаковка нативных библиотек.
- Кнопка «Остановить игру» у запущенной сборки и внизу окна: завершает процесс Minecraft. Остановка пользователем не считается вылетом.

Локальный профиль доступен сразу. Подготовленный Microsoft-вход скрыт по текущему решению; для будущего подключения потребуется зарегистрированное приложение Veyra с доступом к Minecraft API. [Сохранённая инструкция](docs/microsoft-setup.md).

## Как начать

1. Нажмите **Новая сборка**.
2. Укажите название, версию Minecraft и загрузчик.
3. Нажмите **Создать и установить**. Первая установка требует подключения к интернету. Лаунчер подберёт Java и загрузит игру в новую папку.
4. После установки нажмите **Играть**.

Если не хотите заниматься Java, оставьте значение **Автоматически**. Для модов откройте папку сборки и добавьте .jar в её mods. Моды должны подходить к выбранным Minecraft и загрузчику.

## Данные и обновление со старой версии

Новые сборки хранятся в папке Документы/Veyra Launcher/instances. Её путь виден в настройках и открывается кнопкой. Удалённые из списка управляемые сборки перемещаются в соседнюю папку trash для ручного восстановления. Настройки лаунчера и журнал остаются в пользовательской папке приложения.

Время игры учитывается с запуска процесса Minecraft, пока открыт Veyra, и сохраняется каждые 15 секунд, при остановке игры и закрытии лаунчера. Прошлое время до версии 0.4.0 восстановить невозможно; отсчёт начинается с обновления. Если закрыть лаунчер, оставив игру запущенной, дальнейшее время этого сеанса не учитывается.

При первом запуске старая сборка Veyra, если она есть, добавляется в библиотеку. Её папка не переносится. Сборки, созданные прошлой версией в AppData, продолжают работать на прежнем месте.

## Запуск из исходников

Понадобятся Windows, Node.js 22+ и npm:

    npm install
    npm start

Проверка интерфейса и основных действий:

    npm run smoke
    npm run check:auth
    npm run check:accounts
    node scripts/experience-check.js
    node scripts/stop-game-check.js

«check:auth» проверяет протокол на тестовых ответах. «check:accounts» проверяет смену ника и скрытие Microsoft-функций. В этом скрипте сохранены проверки входа, Windows DPAPI и параметров запуска: они возобновятся после включения MICROSOFT_UI_ENABLED в renderer/renderer.js. Им нужна Java 25 из runtime Veyra или из папки VEYRA_JAVA_HOME. Реальный вход требует собственного Client ID и аккаунта с Minecraft Java Edition.

Создание переносимого .exe:

    npm run icon
    npm run dist

Готовый файл будет в dist. Для проверки установки реальной версии из исходников доступен «node scripts/install-check.js vanilla 1.21.8»; второй аргумент можно заменить на fabric, neoforge или forge.

## Что пока вне этой версии

Встроенный каталог модов пока не реализован. Моды добавляются через папку сборки.

## Совместимость NeoForge 26.3.0.56-beta

В этой версии NeoForge проверка обновлений может вернуть null, а код главного меню вызывает у результата ordinal(). Veyra подключает небольшой Java agent только для этой версии: незавершённая проверка получает статус FAILED, остальные результаты сохраняются. Официальные JAR игры остаются исходными. Исходник — compat/NeoVersionGuard.java; включённый JAR — assets/compat/neoforge-version-guard.jar.

Для пересборки агента нужна Java 25 с javac и jar. Задайте VEYRA_JAVA_HOME или используйте runtime, установленный Veyra, затем выполните «npm run compat». Проверка реального запуска на имеющихся ресурсах: «node scripts/launch-compat-check.js ПУТЬ_К_СБОРКЕ»; отдельная тестовая игра создаётся в test-output/compat-game. Она доходит до главного меню и проверяется 50 секунд.

Логотипы в выборе загрузчика: Minecraft — pack.png из официальной версии игры; Fabric — [сайт FabricMC](https://github.com/FabricMC/fabricmc.net/blob/main/assets/logo.png); NeoForge и Forge — официальные аватары [NeoForged](https://github.com/neoforged) и [MinecraftForge](https://github.com/MinecraftForge). Их использование не означает поддержку или одобрение лаунчера этими проектами.
