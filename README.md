# Veyra Launcher

Veyra — лаунчер Minecraft Java Edition для Windows. В главном окне остаётся узкая панель с иконками; экземпляры, установка и настройки находятся в одной рабочей области.

## Возможности

- Отдельная папка игры для каждого экземпляра: Документы/Veyra Launcher/instances/<id>. Внутри находятся собственные mods, saves, resourcepacks, screenshots, версии, библиотеки и ресурсы.
- Vanilla, Fabric, NeoForge и Forge. Доступные версии загрузчика подбираются для выбранной версии Minecraft.
- Автоматический выбор подходящей Java. Если её нет на компьютере, Veyra загружает официальный runtime Minecraft. При желании можно выбрать java.exe или javaw.exe вручную для всего лаунчера или отдельного экземпляра.
- Настройка памяти для всех экземпляров и индивидуальное переопределение. Верхняя граница зависит от ОЗУ компьютера; 2 ГБ оставляются системе.
- Прогресс установки, отмена, повторная попытка, журнал и кнопки открытия папок.
- Своя обложка, цвет, название и заметка для каждого экземпляра. Избранные сборки закрепляются первыми; капсула сборки показывает число запусков и дату последней игры.
- Быстрое переименование кнопкой у названия или клавишей F2, плавная обложка с движением за курсором и анимированная заставка запуска.
- Локальный профиль для одиночной игры.

Локальный профиль не заменяет учётную запись Microsoft. Лицензионные серверы, Realms и сетевые возможности, которым нужна авторизация, пока недоступны.

## Как начать

1. Нажмите **Новый экземпляр**.
2. Укажите название, версию Minecraft и загрузчик.
3. Нажмите **Создать и установить**. Первая установка требует подключения к интернету. Лаунчер подберёт Java и загрузит игру в новую папку.
4. После установки нажмите **Играть**.

Если не хотите заниматься Java, оставьте значение **Автоматически**. Для модов откройте папку экземпляра и добавьте .jar в его mods. Моды должны подходить к выбранным Minecraft и загрузчику.

## Данные и обновление со старой версии

Новые экземпляры хранятся в папке Документы/Veyra Launcher/instances. Её путь виден в настройках и открывается кнопкой. Удалённые из списка управляемые экземпляры перемещаются в соседнюю папку trash для ручного восстановления. Настройки лаунчера и журнал остаются в пользовательской папке приложения.

При первом запуске старый экземпляр Veyra, если он есть, добавляется в библиотеку. Его папка не переносится. Экземпляры, созданные прошлой версией в AppData, продолжают работать на прежнем месте.

## Запуск из исходников

Понадобятся Windows, Node.js 22+ и npm:

    npm install
    npm start

Проверка интерфейса и основных действий:

    npm run smoke

Создание переносимого .exe:

    npm run icon
    npm run dist

Готовый файл будет в dist. Для проверки установки реальной версии из исходников доступен «node scripts/install-check.js vanilla 1.21.8»; второй аргумент можно заменить на fabric, neoforge или forge.

## Что пока вне этой версии

Встроенный каталог модов и Microsoft-авторизация ещё не реализованы. Моды добавляются через папку экземпляра.

Логотипы в выборе загрузчика: Minecraft — pack.png из официальной версии игры; Fabric — [сайт FabricMC](https://github.com/FabricMC/fabricmc.net/blob/main/assets/logo.png); NeoForge и Forge — официальные аватары [NeoForged](https://github.com/neoforged) и [MinecraftForge](https://github.com/MinecraftForge). Их использование не означает поддержку или одобрение лаунчера этими проектами.
